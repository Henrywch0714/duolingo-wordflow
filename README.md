# 词间 · 多邻国核心词单词卡

一个面向 iPhone 的背词网页。词库含 3590 个英文单词及中文释义，按易/中/难和正向/负面/中性分类。

词库整理自[新东方在线多邻国高频核心词](https://liuxue.koolearn.com/duolingo/word/list-1-0/)；难度与情感倾向是个人学习用途的整理结果，不代表网站官方分类。

## 功能

- 在设置中多选简单、中等、难；已有进度的词排在所选词库前部，未学词随机接续并固定编入 Unit/List，其余放入可手动学习的 Other
- 新词“认识 / 不认识”判断后显示中文释义；“不认识”先进入未掌握列表
- 到期系统复习和错题专项采用每词两题（英译中、中译英），全轮题目乱序且同词题不相邻；每题四个即时随机选项与“不记得”，答题后播放正误提示音
- 常规系统复习、系统错词复习和错题专项按答错题数累计同一份错次；自由复习不改错次及到期日期
- 系统复习严格按完整 List 安排（每列 10 词，最后一列按实际词数），学完整列才进入复习计划；每列全部英译中／中译英题完成后一次保存次数、复习日期和错题，未完成列的本轮答题不计入这些记录
- 全部词表、系统复习选择和自由复习列表显示整 List 系统复习次数；旧记录以该列各词最小复习次数作为初始值，此后错题专项不增加整列系统次数
- 自由复习可多选已学 List，或一键复习当天新词；复习列表可按难度和情感色彩筛选
- 自由复习提供“全部已学 List／今日所学 List”视图，今日视图列出今天有新词学习记录且符合筛选的 List，并标明今日新学与可复习词数；勾选后复习其中符合筛选的已学词。学习、系统复习和自由复习均支持全选当前可见 List、半选显示与取消全选
- 错题本按未掌握及具体错次分列表，可单独查看或按 10 的倍数、全部复习
- 全部词表可按 Unit/List/Other 浏览或搜索，展示每词学习次数；旧版未记录准确次数的已学词会明确标注
- 近义词页覆盖全部 3590 词；有匹配的词可在学习或复习结果里一键查看
- 近形词统一列表合并高覆盖率、多段匹配、小编辑距离和 WordNet 词族／派生关系，包含 5168 对匹配、2723 个有匹配的词；支持英文、中文和字母片段搜索，页面及学习／复习展开区与近义词使用相同布局，仅显示单词和中文释义
- 每日按设置分配 N 个新词 List，未完成的 List 次日优先；新词和到期系统复习都先多选 List，再开始本次任务。学习、复习及词表显示同一 Unit/List
- 每次选中的任务单独存档，记录所选 List、已完成和未完成单词；连续 60 分钟无操作自动结束，未完成词仍留待下次学习或复习，也不算作答错
- 学习日历显示每日新词计划、复习积压和实际背过／复习过的单词，可查看每次任务的完成情况；未来日期是根据当前进度的预计安排
- 常规 List 的计划只由已完成的整 List 系统复习次数推进：学完整列次日开始，之后间隔 2、4、7、15、30 天，并保持 30 天一次；答错不重置整列循环
- 系统复习另设错词板块，新版常规系统复习中答错的词从次日进入独立的 1、2、4、7、15、30 天循环；已有错词只由其专属题组推进或重置，常规 List 中再次答错只累计错次。错词任意一题错就回到 1 天；完成间隔 30 天后的那轮且两题全对才自动移出。移出不清零错题本累计错次
- 当日到期错词每 10 个组成“错词 List 1、2、3…”，最后一列按实际词数；可与常规 List 同屏勾选、全选。分组在开始任务时锁定，正常完成或中途退出均按整 List 保存规则处理
- 同词同时在常规和错词 List 中时，会各出一组英译中／中译英题，随机混排，以独立题组标识分别记分、存档、恢复草稿及计算任务完成度。学习日历及积压按复习词次统计，同词可计为两个复习词次
- IndexedDB 本地保存，支持导出与导入 JSON 备份
- 用户名和密码注册/登录；每位用户的进度单独保存在 MongoDB，登录状态保持 90 天
- 本机缓存与云端自动同步；冲突时明确选择本机或云端
- PWA 支持添加到 iPhone 主屏幕，资源缓存后可离线使用

近义词来自 [Princeton WordNet](https://wordnet.princeton.edu/)，只保留两词都在本词库中且属于同一个同义词集的直接配对。1544 个词有至少一个词库内匹配；其他词显示暂无匹配。不同词义下并非总能互换，需结合中文释义判断。版权与许可见 [WORDNET_LICENSE.txt](./WORDNET_LICENSE.txt)。

系统复习升级：已有 List 保留复习次数，按整列已完成次数恢复其间隔档位；能确定上次整列复习日的记录会据此重新排期。旧错题本及错次数完整保留，新系统错词板块从新版系统复习的错词开始积累。旧版进行中的系统复习草稿会结束，已完成整列记录保留，未完成题组不混入新规则。

同步接口阻止旧版网页以较低状态版本覆盖新版错词计划；不同设备应刷新网页后使用新规则。

独立题组可能使大批量任务草稿超过旧版 1.5 MB 同步限制；服务端现在允许最多 4 MB 学习状态，留在 [Vercel Function 4.5 MB 请求／响应限制](https://vercel.com/docs/functions/limitations#request-body-size)以内。已用整个词库同时选入常规和错词复习的草稿验证体积。

## 近形词规则

四种条件命中任意一种即进入同一近形词列表，词对去重并保留所有匹配原因，列表不分相似结构等级：

- 高覆盖率：连续匹配段至少 2 个字母，至少一段 3 个字母；匹配段按双方字母顺序、不重叠，合计覆盖较长单词的 70% 以上。
- 多段匹配：至少两段、每段至少 2 个字母，至少一段 3 个字母，合计覆盖较长单词的 60% 以上。
- 编辑距离：使用含相邻字母换位的 Damerau–Levenshtein 距离；双方至少 3 个字母，短词（较短一方不超过 4 字母）最多 1 次编辑，其他最多 2 次且不超过较长单词长度的 25%。
- 词族／词根词缀：依据 WordNet 3.1 的词汇派生指针、由形容词派生的副词、分词关系，以及共享同一个词义节点的直接派生形式。不把仅有共同后缀的词自动解释为同根；这不是覆盖全部词源的完整词根词缀词典。来源及许可沿用上面的 WordNet 链接。

查看近形词不修改学习次数、错次、系统复习次数或计划。关系表是共享静态文件，不需要新增数据库集合或实时外部 API。默认一页 20 个词，直接展示关联词及中文释义；词卡内点击“查看近形词”后，以与近义词相同的标签样式展示全部关联词及中文释义。

构建时将 WordNet 3.1 的 `data.noun`、`data.verb`、`data.adj`、`data.adv` 放在 D 盘目录，然后运行 `node scripts/build-nearforms.cjs <该目录>`，生成 `nearforms.json`。`npm test` 验证规则、关系表完整性、查询与展开对学习记录无副作用。

## 本地运行

使用任意静态文件服务器在本目录启动，不能直接双击 `index.html`，因为词库通过 `fetch` 加载。

例如：`node serve.mjs`

浏览器打开 `http://127.0.0.1:4173`。

## 网站地址

账户版使用 [Vercel 网站](https://duolingo-wordflow.vercel.app/)。GitHub Pages 旧网址会跳转到此地址，让 iPhone Safari 的登录 Cookie 与 API 保持同源。用户进度不会上传到 GitHub。

## 云同步部署

将同一个仓库导入 Vercel，启用 Node.js Functions `api/auth.js` 和 `api/sync.js`。在项目的 Environment Variables 设置：

- `MONGODB_URI`：Atlas 数据库连接串，使用仅授权 `wordflow.progress` 集合的数据库用户。账户、会话与每位用户的进度均保存在该集合，用不同 `_id` 前缀隔离。

密码使用加盐 scrypt 摘要保存；登录会话使用 90 天有效的 Secure、HttpOnly、SameSite Cookie。Atlas 需要允许 Vercel Function 的出站 IP 访问数据库。首次在第二台设备登录时会下载同一账户的云端进度；若两边都有进度，网页会要求选择保留哪一份。
